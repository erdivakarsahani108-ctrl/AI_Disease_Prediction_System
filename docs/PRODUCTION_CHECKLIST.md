# Production Checklist

- [ ] Set a unique high-entropy SECRET_KEY.
- [ ] Set a strong PostgreSQL password.
- [ ] Use HTTPS and secure reverse proxy.
- [ ] Configure email/SMS provider for OTP delivery.
- [ ] Disable development OTP responses.
- [ ] Run Alembic migrations.
- [ ] Load only verified medicine records with provenance.
- [ ] Configure backups and restore drills.
- [ ] Configure centralized logging/metrics/alerts.
- [ ] Perform security and penetration testing.
- [ ] Validate models on independent real-world datasets.
- [ ] Establish clinical governance and human escalation.
- [ ] Complete jurisdiction-specific legal/regulatory review.
